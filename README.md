# job4j_grabber

Агрегатор вакансий — система автоматического сбора вакансий с сайтов по расписанию.

## 📖 О проекте

**job4j_grabber** — это приложение, которое запускается по расписанию и собирает вакансии с различных сайтов, сохраняя их в базу данных.

### Основная задача

Система запускается **раз в минуту** (период настраивается в `app.properties`), собирает вакансии с сайта и записывает их в базу данных.

**Первый сайт для парсинга:** [career.habr.com](https://career.habr.com)

**Раздел:** [Java-разработчик](https://career.habr.com/vacancies/java_developer)

Программа должна считывать все вакансии с **первых 5 страниц**, относящиеся к Java, и записывать их в базу.

## 🎯 Цели расширения

1. **Добавление новых сайтов без изменения кода** — архитектура должна позволять подключать новые источники вакансий через конфигурацию.
2. **Параллельный парсинг сайтов** — возможность одновременного сбора данных с нескольких источников.

## 🛠 Стек технологий

- **Java 17**
- **Maven** — сборка и управление зависимостями

## 📋 Требования

- JDK 17 или выше
- Maven 3.8+
- PostgreSQL (или другая СУБД)

## ⚙️ Конфигурация

Основные настройки хранятся в файле `app.properties`:

```properties
# Период запуска задачи (cron-выражение)
cron.time=0 0/1 * * * ?

# Настройки базы данных
jdbc.url=jdbc:postgresql://localhost:5432/grabber
jdbc.username=postgres
jdbc.password=password

# URL для парсинга
site.url=https://career.habr.com/vacancies/java_developer
site.pages=5
